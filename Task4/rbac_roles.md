# Таблица ролей и полномочий для доступа к кластеру Kubernetes

| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin | Полный доступ ко всем ресурсам кластера: создание, чтение, обновление, удаление всех объектов во всех namespace. Управление RBAC, сетевыми политиками, хранилищами. | Руководители IT-отдела, главный архитектор |
| namespace-admin | Полный доступ к ресурсам в определенном namespace: создание, чтение, обновление, удаление pods, deployments, services, configmaps, secrets. Управление ресурсами внутри namespace. | Владельцы продуктов, тимлиды команд разработки |
| developer | Чтение и обновление ресурсов в namespace: просмотр pods, deployments, services, logs. Создание и обновление deployments, configmaps. Запрещено удаление критичных ресурсов и изменение secrets. | Разработчики, бизнес-аналитики |
| devops-engineer | Управление инфраструктурными ресурсами: создание и управление deployments, services, ingress, persistent volumes. Настройка мониторинга и логирования. Управление CI/CD pipeline. Доступ к secrets для настройки интеграций. | DevOps-инженеры, инженеры по эксплуатации |
| viewer | Только чтение ресурсов в namespace: просмотр pods, deployments, services, logs. Просмотр метрик и статуса приложений. Запрещены любые изменения. | Менеджеры проектов, аналитики BI, специалисты по ИБ |
| security-auditor | Чтение всех ресурсов кластера для аудита безопасности: просмотр RBAC политик, network policies, pod security policies. Просмотр логов и событий безопасности. Запрещены любые изменения. | Специалисты по информационной безопасности |
